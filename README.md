# Linux Operations

## Project Description
This project is part of my AI/DevOps learning roadmap (Month 4, Week 1).

I practiced Linux terminal commands to manage files, create backups, and analyze server logs.

## Project Structure
- `src/` — Contains Python source files.
- `logs/` — Contains server log files.
- `backups/` — Stores backup copies of logs.
- `reports/` — Contains extracted error reports.
- `README.md` — Project documentation.

## Linux Commands Learned
- `pwd` — Show current directory.
- `ls` — List files and folders.
- `cd` — Change directory.
- `mkdir` — Create directories.
- `touch` — Create empty files.
- `cat` — Display file contents.
- `echo` — Write text.
- `cp` — Copy files.
- `grep` — Search for specific text.
- `>` — Write output to a file, replacing existing content.
- `>>` — Append output without deleting existing content.

## What I Practiced
1. Created a Linux project structure.

Linux CLI, file management, log analysis, backups, and basic DevOps operations
